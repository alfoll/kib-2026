# Инструкции Codex: оформление материалов КИБ-2026

Область действия: весь репозиторий. Это проект самостоятельной конференционной
статьи. Не выбирать тему, не писать исследовательское содержание и не заявлять
результаты без соответствующего запроса пользователя.

## Источники правил

Сначала прочитать `REQUIREMENTS.md`, затем `README.md`. Требования КИБ зафиксированы
по состоянию на 20.10.2026. Исходные документы и извлечённый текст находятся в `docs/`.
Отличать явные правила организаторов от решений шаблона и редакционных пожеланий.
Не выдавать шаблон за официальный. При противоречиях источников явно описать их;
не менять нормативное оформление по своему усмотрению.

## Что редактировать

Содержание: `content/metadata.tex`, `abstract.tex`, `body.tex`, `references.tex`.
Оформление централизовано в `kib2026.cls`. Менять класс только для исправления
реального расхождения с источниками или по прямому указанию пользователя.
Не переносить в статью детали НИР, которые не определены в самой статье.

## Неподвижные параметры

- А5 148 x 210 мм, книжная ориентация; поля 23/25/17/18 мм (верх/низ/лево/право).
- Настоящий Times New Roman; Word-пункты задаются в `bp`. Запрещена скрытая подмена.
- Основной текст 10, аннотация/УДК/организация/подписи 9, авторы/название 11,
  библиография 8. Не сжимать шрифт, геометрию, межстрочный интервал для подгонки.
- Абзац 5 мм, одинарный интервал, по ширине, русские автоматические переносы.
- Аннотация: один абзац, 5–8 фактических строк, цель и основной результат,
  без повторения названия. Курсив аннотации официально не требуется.
- Заголовки разделов необязательны; если есть: 10, полужирные, по центру,
  обычный регистр. Для заголовка доклада: прописные, 11, полужирные.
- Не добавлять титульный лист, оглавление, рамки, колонтитулы или номера страниц.
  Это решения шаблона, согласованные с видом официального образца.
- Чёрно-белые рисунки. Подпись рисунка снизу по центру; таблицы сверху справа,
  обе 9. Использовать `\caption` и `\label`; для ссылок `\figref`, `\tabref`.
- Нумерация рисунков/таблиц появляется, когда объектов данного вида больше одного.
  Для нескольких формул использовать `equation`; одну без ссылок — `equation*`.
  Номер формулы справа в круглых скобках, формула по центру.
- Источники: ссылки `[1]`, список `1.`, порядок первого цитирования.
  Не выдумывать библиографию. Проверить соответствие утверждений источникам.

## Проверка после изменений

1. `python scripts/build.py` (Windows: `py scripts/build.py`).
2. Для финальной статьи: `python scripts/build.py --check`.
3. Просмотреть ОБЕ страницы PDF, при доступном Poppler отрисовать:
   `pdftoppm -scale-to 1400 -png build/main.pdf build/page`.
4. Проверить поля, размеры, читаемость, отсутствие обрезки, выходов за поля,
   корректность ссылок и встраивание шрифтов. Исправить предупреждения о
   пропавших символах, ссылках, переполненных строках.
5. Должно быть ровно две ПОЛНЫЕ страницы. Количество страниц автоматизировано,
   полнота — ручная проверка. Не добавлять пустые страницы, фиктивные данные,
   заполнитель, принудительные разрывы или `\vfill` для имитации выполнения правила.
6. Не считать исходный демонстрационный текст готовой статьёй. Его необходимо заменить.
7. Если TNR отсутствует, основная сборка обязана завершаться ошибкой. Допустима
   только явно маркированная проверка `--preview`; она не подтверждает финальную
   пагинацию. Сообщить ограничение и пересобрать после установки шрифта.
8. Автопроверка не доказывает новизну, корректность исследования, полноту страниц,
   монохромность встроенных изображений или соответствие DOCX. Проверить вручную.

## Сдача и безопасность файлов

КИБ требует DOCX И PDF. LaTeX формирует PDF; DOCX оформляется отдельно в
`docs/official-template.docx` с обязательной сверкой обеих версий. Не выдавать
PDF, вставленный картинками в Word, или непроверенную конвертацию за корректный DOCX.
Не публиковать статью, не отправлять в оргкомитет, не менять доступ репозитория
без соответствующего указания пользователя. Шрифты, сборочные файлы и документы
с подписью/персональными согласиями в Git не добавлять.
