# Times New Roman

Основная сборка требует настоящий Times New Roman: обычный, полужирный,
курсивный и полужирный курсивный. Установите шрифты в ОС из законно доступного
вам источника (например, вашей установки Microsoft Office).

Альтернатива: поместите сюда четыре лицензированных файла с именами
`times.ttf`, `timesbd.ttf`, `timesi.ttf`, `timesbi.ttf`.
Если ваши файлы называются иначе, сделайте локальные копии с этими именами.
Файлы шрифтов исключены из Git: проект их не распространяет.

`preview.tex` явно использует DejaVu Serif только для предварительного просмотра.
Его PDF не соответствует требованию Times New Roman; после установки TNR
обязательно пересоберите `main.tex` и заново проверьте переносы и объём.
