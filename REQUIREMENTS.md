# Полный перечень требований КИБ-2026

Проверено 20 октября 2026 года. Этот файл сохраняет правила для последующей работы
автора и Codex. Изменения сайта после этой даты требуют повторной сверки.

## Источники

- **S1:** https://kib.mephi.ru/abstracts/requirements — требования к оформлению.
- **S2:** `docs/official-information.docx` — предоставленное пользователем
  «инф_сообщение КИБ-2026 (ИМ).docx»; текстовая копия `docs/source-information.txt`.
- **S3:** `docs/official-template.docx` — предоставленный пользователем
  «Шаблон 2026.docx»; текстовая копия `docs/source-template.txt`.
- Направления: https://kib.mephi.ru/abstracts/directions
- Подача: https://kib.mephi.ru/information-message и https://kib.mephi.ru/abstracts
- Даты: https://kib.mephi.ru/dates

Численные параметры S1 и S2 совпадают. S3 дополняет их правилами аннотации,
разделов, иллюстраций, таблиц, формул и литературы. Внутренние стили DOCX могут
содержать наследованные настройки; нормативной основой служат явно написанные
требования, а не случайный стиль отдельного фрагмента образца.

## 4. Рисунки, таблицы и формулы

| ID | Требование | Источник |
|---|---|---|
| F01 | Рисунки, таблицы и формулы нумеруются, если их больше одного; считать отдельно каждый вид | S3 |
| F02 | Цветные рисунки не допускаются | S3 |
| F03 | В ссылках на рисунки и таблицы есть пробел: «рис. 2», «табл. 3» | S3 |
| F04 | У рисунков есть подрисуночные подписи | S3 |
| F05 | Подпись: «Рис. 1. Название», кегль 9, по центру | S3 |
| F06 | Название таблицы размещается сверху | S3 |
| F07 | Название: «Таблица 2. Название», кегль 9, по правому краю таблицы | S3 |
| F08 | Формулы по центру | S3 |
| F09 | При ссылках на формулы номер справа, в круглых скобках: (2) | S3 |

Совместное чтение F01 и F09: единственная формула без ссылки может быть без
номера; для ссылки на единственную формулу допустим номер (1); несколько формул
нумеруются. Правило для единственной формулы не описано подробнее, поэтому это
явно зафиксированное решение шаблона. Для рисунков и таблиц единственный объект
остаётся с подписью, но без номера.

## 5. Литература

- Ссылки в тексте — квадратные скобки.
- Порядок записей — порядок ссылок на источники в тексте (в проекте: первого упоминания).
- Номер записи заканчивается точкой: `1.`, а не `[1]`.
- В записи сначала фамилия автора/соавторов, затем инициалы.
- Далее указываются издательство / журнал / конференция, год и страницы;
  название работы включается по образцам S3.
- Размер записей — 8 пт, выравнивание по ширине.
- DOI, URL, ISSN, EDN встречаются в примерах, но обязательность всех этих полей
  для каждой записи не установлена. Приводить только существующие реквизиты.

Источники: S1–S3. Минимальное/максимальное количество источников не установлено.

## 6. Тематические направления 2026 года

1. Доверенная электронная компонентная база и программно-аппаратные комплексы для критической информационной инфраструктуры.
2. Защищенные компьютерные системы и технологии.
3. Техническая защита информации.
4. Безопасность разработки программного обеспечения.
5. Интеллектуальное управление сетевой безопасностью.
6. Правовые, этические и социально-технические аспекты противодействия киберугрозам.
7. Теоретическая и практическая криптография.
8. Информационно-аналитические системы безопасности.
9. Проблемы информационной безопасности в системе Высшей школы.

## 7. Сопровождение подачи (не настройки статьи)

- До 25 октября 2026 г. — регистрация для подачи и загрузка материалов.
- Предоставляются материалы, акт экспертного заключения о возможности открытой
  публикации и согласие на обработку персональных данных.
- В сообщении также описана отправка электронной почтой с заявлением в свободной
  форме в теле письма. Основной описанный путь — личный кабинет сайта; актуальный
  доступный способ следует сверить непосредственно перед подачей.
- До 1 ноября — рассмотрение; до 20 ноября — программа; до 25 ноября — регистрация
  для участия. Ноябрьская дата не заменяет октябрьский срок материалов.
- Конференция 2–3 декабря 2026 г., Москва, НИЯУ МИФИ, очно, без регистрационного взноса.
- Секционный доклад до 10 минут, обсуждение до 3; пленарный — 20 и 5 минут.
- Сборник планируется с индексацией РИНЦ; лучшие доклады рекомендуются в журналы ВАК.

Источник: S2. Эти сведения не нужно включать в текст статьи.

## 8. Что НЕ объявлено обязательным

В изученных источниках не заданы обязательные английская аннотация, ключевые
слова, отдельные англоязычные References, объём в знаках, число источников,
фиксированная структура разделов, готовая программная реализация или обязательный
эксперимент при наличии новых идей. Не добавлять такие требования от себя.
Курсив аннотации из требований к НИР сюда не переносится.

## 9. Решения этого проекта, а не дополнительные требования КИБ

- XeLaTeX, UTF-8, русская автоматическая расстановка переносов.
- Размеры шрифта в `bp` (Word-пункт 1/72 дюйма).
- Одинарная стандартная строка без дополнительного множителя; базовые интервалы
  12/10,8/9,6/13,2 bp для кеглей 10/9/8/11. Организаторы не задают точный шаг в пунктах.
- Пустые колонтитулы и отсутствие номера страницы, как в предоставленном шаблоне.
  Расстояния колонтитулов при их пустом содержимом визуально не проявляются.
- Математические символы набираются стандартными математическими шрифтами LaTeX;
  отдельная гарнитура для формул организаторами не уточнена. Обычный текст — TNR.
- Аннотация оформляется одним абзацем для надёжного подсчёта строк.
- Автопроверка дополняет, но не заменяет визуальную и научную проверку.
- Этот LaTeX-класс не является официальным шаблоном организаторов.
